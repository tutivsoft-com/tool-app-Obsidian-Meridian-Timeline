# Meridian Timeline Privacy

Meridian reads note metadata and date text locally through Obsidian APIs. It stores settings and parsed timeline data in Obsidian plugin data; that cache can include note paths, titles, headings, tags, and timestamps. Protect the local Obsidian profile and vault as you would other local note data.

Meridian does not send note contents to TutivSoft Constance and does not use AI. Billing requests may send the installation identifier and the account, entitlement, purchased-use, or checkout metadata needed for usage management. The plugin tracks the first three successful operations per local calendar day in its settings; later operations require purchased-use verification.
