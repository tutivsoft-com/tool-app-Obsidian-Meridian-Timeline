# Meridian Timeline User Guide

## Open a timeline

1. Enable Meridian Timeline in Obsidian.
2. Choose Meridian Timeline: Open timeline from the command palette.
3. Let the initial scan finish, or cancel it and run it again later.
4. Select Refresh after editing notes to include their latest dates.

## Configure dates

1. Open Settings, then Meridian Timeline.
2. Choose the frontmatter properties to use. The defaults are date, start, end, created, and modified.
3. Add folders or note patterns to ignore when appropriate.
4. Use the review list to find notes with missing or malformed dates. Correct the note or adjust the configured property and refresh.

Meridian reads supported ISO and common month/day dates, years, decades, approximate dates, BC/BCE labels, and configured era names. Unsupported or ambiguous values are shown for review rather than silently converted.

## Explore events

- Search and filter by text, folder, tag, date range, event type, or uncertainty.
- Group events by folder or tag.
- Use zoom, pan, Fit all, and Focus selected to move around the chronology.
- Select an event to open its source note.
- Save named views for filter configurations you use often.

Meridian reads notes but does not edit them.

## Usage and billing

Three successful timeline operations are free per local calendar day. After the daily allowance, Meridian needs a purchased use to complete an operation. Settings provide billing email, balance, and checkout controls. Purchased-use verification and checkout require network access and send installation/account billing metadata, not note contents.

## Troubleshooting

- Check that a note uses one of the configured date properties or a supported date format.
- Check ignored folders and patterns if an expected note is missing.
- Use Refresh after changing a note.
- If usage verification is unavailable after the free allowance, reconnect and try again.
